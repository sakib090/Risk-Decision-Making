# Risk and Decision Making — ECS7005P (MSc Data Science, QMUL)

Coursework completed as part of the MSc Data Science programme at Queen 
Mary University of London.

## Topics Covered

### Bayesian Networks
- Designed and trained a Bayesian Network DAG modelling student academic 
  performance using PyAgrum
- Computed conditional probability tables from real dataset
- Performed probabilistic inference and counterfactual reasoning
- Analysed causal impact of stress on grades

### Model Evaluation
- Built and evaluated an AI song success prediction model
- Computed confusion matrices across multiple probability thresholds
- Plotted ROC curves and identified optimal classification threshold
- Discussed causal Bayesian networks vs data-driven classification

### Decision Making Under Uncertainty
- Computed expected utility for a prize box game
- Built influence diagram using PyAgrum
- Analysed emergent risk in multi-agent navigation systems
- Discussed non-stationarity and behavioural feedback in AI deployment

## Tech Stack
- Python
- PyAgrum
- pandas / NumPy
- Matplotlib
- Jupyter Notebook
